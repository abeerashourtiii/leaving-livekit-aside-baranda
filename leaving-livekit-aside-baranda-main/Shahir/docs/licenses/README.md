# إثباتات تراخيص المحتوى (الموسيقى)

هذا هو المكان المعتمد فى المشروع لحفظ **إثبات ترخيص أى ملف موسيقى** يُضاف لمكتبة التطبيق. السبب: التطبيق يقدّم هذه المقاطع لكل المستخدمين
داخل إعلاناتهم، فلو ظهر نزاع حقوق نشر فالمسؤولية الأولى على صاحب التطبيق (راجع سياسة حقوق النشر داخل التطبيق،
وبند التعويض فى شروط Stability AI §11 الذى يُلزم *المستخدم لديهم = أنت* بتعويضهم).

## المجلدات

```
docs/licenses/
├─ README.md                  ← هذا الملف (القواعد)
├─ music-licenses.md          ← سجل التراخيص: صف لكل مقطع موسيقى (أنشئ صفًا قبل رفع أى مقطع)
└─ music/
   ├─ stability-ai_terms-of-service_effective-2026-09-30.pdf              ← شروط الخدمة (ToS) — نسخة مؤرَّخة
   └─ stable-audio_commercial-and-usage-licensing_kb-article.pdf          ← مقال «الترخيص التجارى والاستخدام» لـ Stable Audio
```

> ⚠ هذه الملفات مجرد **توثيق داخلى**. لا تُشحن داخل التطبيق: تأكد أن `assetBundlePatterns` فى `app.json` لا يضمّ مجلد `docs/`
> (الأفضل تغييره من `["**/*"]` إلى `["assets/**/*"]` ثم تجربة بناء APK قبل الاعتماد).

## قواعد إضافة مقطع جديد (لكل مقطع)

1. **ولّد المقطع من حساب تملكه الشركة/صاحب التطبيق** (وليس حسابًا شخصيًا لموظف)، واحتفظ بإيصال الاشتراك لو كانت الخطة مدفوعة.
2. **احفظ الملف الأصلى** كما نُزِّل من الأداة (WAV/MP3) مع **نص الـ prompt** وتاريخ التوليد ولقطة من سجل التوليد (Generation History).
   هذه المواد حساسة وكبيرة، فلا ترفعها لمستودع عام؛ احفظها فى مساحة خاصة (Drive مغلق/NAS) وسجّل مرجعها فى `music-licenses.md`.
3. **أضف صفًا** للمقطع فى `music-licenses.md` (المصدر، الخطة، تاريخ التوليد، بصمة SHA-256 للملف، اسم ملف الإثبات).
4. **عند رفع المقطع من لوحة الأدمن → المكتبة الموسيقية** اكتب فى خانة «مصدر الترخيص» نفس المرجع المختصر، مثال:
   `Stable Audio — Pro — 2026-10-12 — stable-audio_commercial-and-usage-licensing_kb-article.pdf`
   (الحقل إلزامى، ويُحفظ فى `music_tracks.license_note` ويظهر للأدمن تحت كل مقطع).
5. **جدّد الإثبات** كل ما تغيّرت شروط المزوّد (Stability تحتفظ بحق تعديل الشروط — §12.b): نزّل نسخة PDF جديدة بتاريخها ولا تحذف القديمة.
6. **لا تحذف** إثبات مقطع ما دام منشورًا أو مستخدمًا فى إعلانات قديمة.

## ما يغطيه ترخيص Stable Audio وما لا يغطيه (خلاصة المستندين المرفقين)

| الموضوع | ما ورد |
|---|---|
| الاستخدام التجارى | مسموح فى كل الخطط (Free / Solo / Creator / Pro / Studio / Max / pay-as-you-go API)، وفقًا للشروط وسياسة الاستخدام المقبول. |
| الاستخدام داخل تطبيقات الموبايل والويب والألعاب | مسموح صراحةً كموسيقى خلفية/أصول صوتية، **حتى فى الخطة المجانية**. |
| فيديوهات مُموَّلة ومنصات التواصل والإعلانات التجارية | مسموحة (YouTube/Twitch/السوشيال، إعلانات، بودكاست، مشاريع عملاء). وهذا يغطى ميزة «وسّع انتشار إعلانك». |
| التوزيع كمكتبة (stock music / sound library) | مسموح تجاريًا مع التقيّد بالشروط — وهو توصيف مكتبة الموسيقى فى التطبيق. |
| ملكية المخرجات (Output) | تنتقل إليك «بالقدر الذى يسمح به القانون» (ToS §4.a). **قد تُنتج الأداة مقاطع متشابهة لمستخدمين آخرين.** |
| ضمان عدم التعدى على حقوق الغير | **لا يوجد.** المسؤولية عليك (§4.a و§11 والمقال: «You are responsible for ensuring that your use does not violate anyone else’s rights»). |
| التعويض (Indemnification) | لا تعويض من Stability فى الخطط العادية؛ يتطلب اتفاقية **Enterprise** فقط. بل أنت تعوّضهم (§11). |
| الحد الأقصى لمسؤوليتهم | الأكبر بين 100 دولار وما دفعته آخر 6 أشهر (§11). |
| حظر | إظهار المخرجات على أنها من تأليف بشر (§3.b.9)، وإزالة العلامات/بيانات المصدر (§3.b.10)، وتدريب نماذج منافسة على المخرجات (§3.b.2). |
| نماذج الأوزان المفتوحة (Self-hosting) | تخضع لـ Community License، ولها حد إيراد سنوى 1 مليون دولار؛ تحقق منها إن استخدمتها. |
| النزاعات | تحكيم ملزم فى كاليفورنيا لمستخدمى أمريكا (§13) — وللمستخدمين خارجها بحسب الكيان المتعاقد (§1). |

### نقاط تحتاج انتباهك (لهذا يجب توثيق كل مقطع)
- **قابلية حماية المخرجات بحق المؤلف غير مؤكدة** فى كثير من الدول (غياب التأليف البشرى). فلا تدّعِ احتكار المقطع ولا تسجّله كمؤلَّف بشرى، ولا تقدّم المقاطع للمستخدمين على أنها «ألّفها فنانون».
- **لا تُسجِّل المقاطع فى Content ID أو موزّعى الموسيقى** باسمك: قد يؤدى لبلاغات خاطئة ضد فيديوهات مستخدميك أو ضد من يستخدم مقطعًا مشابهًا.
- **اسمع كل مقطع قبل نشره** وتأكد أنه لا يشبه لحنًا مشهورًا (قد تُنتج أدوات التوليد مقاطع قريبة من أعمال موجودة).
- المقاطع **الخمسة المدمجة** فى `assets/music` ليس لها مرجع ترخيص فى المشروع. أضف إثباتها فى السجل أو استبدلها بمقاطع موثّقة (راجع `music-licenses.md`).
- الـ PDF المرفقان لقطات من صفحات ويب (ToS سارية 2026-09-30، ومقال معرفة بحقوق 2025). هما إثبات جيد لكنهما ليسا عقدًا موقَّعًا؛ احتفظ أيضًا بلقطات حسابك وإيصالاتك.
