# خطة الاختبار (بسيطة) — شغّلها على النسخة قبل أى نشر

> القاعدة الآن: **لا ميزات جديدة**؛ أى فشل هنا يُصلَح فقط. أرسل لى ناتج أى خطوة تفشل كاملًا.

## 1) على جهازك (من مجلد `diarino-app`)
```bash
npm ci
npm run typecheck
npm run test:i18n
node --experimental-strip-types scripts/test-recommendation.mjs
node --experimental-strip-types scripts/test-units.mjs      # أو: npm run test:units
```
| الخطوة | المتوقع |
|---|---|
| `npm run typecheck` | **قد يفشل أولًا** لأن `src/types/supabase.ts` لا يعرف الدوال/الأعمدة الجديدة. ولّده أولًا: `docs/types-regeneration.md` (`npm run types:gen -- --local`) ثم أصلح حتى يصفر |
| `npm run test:i18n` | `✓ التغطية ≥ العتبات` (كل المراحل 100%) |
| `test-recommendation.mjs` | `كل الاختبارات نجحت (12)` |
| `test-units.mjs` | `اختبارات الوحدة: 40 نجح، 0 فشل` — يغطى المحقِّقات (A4/A5: العمر ≥ 18، الحد الواحد على الأقل، الأسعار والمدد)، والحد الأدنى للإصدار، وضبط التخزين المسبق D1، وتطبيع العربية M5 |

## 2) قاعدة بيانات تجريبية/محلية
1. طبّق كل `supabase/migrations` بالترتيب (آخرها `20261116100004_sponsored_requires_limit.sql`).
2. شغّل `supabase/verification/pre-deploy-checks.sql`: راجع §1–6، ثم **§7** (صفوف تخالف قيود NOT VALID) — لازم 0 صف — ثم فعّل أسطر `VALIDATE CONSTRAINT` فى §8.
3. اختبار حسابين للتسجيلات: `node scripts/test-live-recording-privacy.mjs` (مشروع تجريبى فقط؛ المتغيرات فى رأس الملف).
4. A2: كحساب معلن اطلب `select * from ad_promotions` ⇒ يجب أن **يفشل** (صلاحيات الأعمدة)، وبأعمدة صريحة ⇒ ينجح؛ و`confirm_promotion_payment` ⇒ jsonb بحقول آمنة فقط.

## 3) جهاز/متصفح (يدوى — لم يُجرَّ شىء منه حتى الآن)
- **أندرويد + آيفون + الويب:** تسجيل دخول/خروج، نشر إعلان (الأذونات)، البحث والخريطة، الشات، تشغيل ريلز (D1: راقب استهلاك البيانات بعدّاد D3)، إعادة بث مسجّل بالرابط الموقّع، التنبيهات، تبديل الإنجليزية/العربية وإعادة التشغيل (RTL على الموبايل).
- **الأدمن (ويب):** نافذة تأكيد على سعر 0، رفض الحقول الفارغة، إضافة ريل مميز بلا حد (يُرفض) ثم بتاريخ انتهاء، «تجاهل» فى الدعم (يختفى ويُحذف بعد 30 يومًا)، تبويب «المناطق المقترحة».
- **نسخة قديمة منشورة (إن وُجدت):** قوائم الترويج/المساحة الإعلانية، بدء بث، اقتراح منطقة — راجع «أثر الإغلاق» فى `CHANGES_AND_TODO.md` و`supabase/staged/README.md`.
