# خوارزمية التوصية — ريلز «لك» (Shahir)

ترتيب الريلز العادية فى الصفحة الرئيسية مخصّص لكل مستخدم بحسب اهتماماته وسلوكه، **بعد** الإعلانات الافتتاحية المفعّلة (الأحدث تفعيلًا أولًا)
ثم الإعلانات المميزة تُدرَج أثناء التصفح كما كانت. يعمل بنفس الكود على أندرويد وآيفون والويب وAPK.

## الملفات
| الملف | الدور |
|---|---|
| `lib/recommendation/engine.ts` | المنطق الحسابى النقى: الخصائص، تحديث ملف الاهتمامات، التقييم، الترتيب مع التنويع والاستكشاف، التضاؤل الزمنى. |
| `lib/recommendation/store.ts` | التخزين (AsyncStorage/localStorage) + المزامنة مع الحساب (`user_interest_profiles`) + استقبال الإشارات + مفاتيح التحكم. |
| `lib/hooks/useForYouFeed.ts` | يربط الترتيب بالقائمة: يقفل الريل النشط وما حوله ويعيد ترتيب الذيل فقط. |
| `components/reel/ReelCard.tsx` | يقيس مدة المشاهدة الفعلية وإعادة التشغيل لكل ريل. |
| `app/(tabs)/index.tsx` | يجمع مجموعة مرشّحة (حتى 4 صفحات)، ويضع الافتتاحية أولًا ثم الريلز المرتّبة. |
| `app/settings.tsx` | «تخصيص الريلز بحسب اهتماماتي» (إيقاف/تشغيل) و«إعادة ضبط التوصيات». |
| `supabase/migrations/20261104000000_user_interest_profiles.sql` | جدول ملف الاهتمامات (RLS: كل مستخدم صفّه فقط). |
| `scripts/test-recommendation.mjs` | اختبارات المحرك: `node --experimental-strip-types scripts/test-recommendation.mjs` |

## الإشارات وأوزانها (من `RECO` فى engine.ts — عدّلها من هناك)
مشاركة 6 · تعليق 5 · حفظ 5 · متابعة معلن 8 (للمعلن) · إعجاب 4 · فتح التفاصيل 2 · بحث 3 ·
مشاهدة: نسبة المشاهدة ×1.6، +1 لو شاهده كاملًا (≥90%)، +1.7 لكل إعادة تشغيل (حتى 3)، وتخطٍّ أقل من 1.5ث = −1 (وأقل من 3ث = −0.35).
كل إشارة تُوزَّع على خصائص الريل: النوع، الغرض (بيع/إيجار)، المحافظة، المعلن، شريحة السعر، الغرف، المميزات.

## الترتيب
`الدرجة = 1.9×الاهتمام + 0.9×الحداثة + 0.6×الشعبية + 0.55×(معلن تتابعه) + 0.25×(مثبّت) − 1.3×(شاهدته مؤخرًا) + استكشاف عشوائى مستقر`
ثم: تنويع (لا يتتالى نفس المعلن/النوع)، وكل خامس ريل «استكشافى» خارج اهتماماتك حتى لا تعلق فى فقاعة واحدة.
الاهتمام يتضاءل تلقائيًا: يقل للنصف كل 14 يومًا. المستخدم الجديد (بلا سجل) يرى مزيجًا من الأحدث والأشهر.

## قواعد الثبات أثناء السحب
الريل النشط + الأربعة التالية (المحمّلة مسبقًا) + كل ما قبلها **مقفول**؛ الذيل فقط يُعاد ترتيبه بعد كل تفاعل أو صفحة جديدة،
فتتكيّف التوصيات لحظيًا دون أن يتغير الريل تحت إصبع المستخدم.

## الخصوصية والتحكم
الملف مُلخَّص (أوزان) لا سجل حركات، يُخزَّن محليًا ويُنسَخ لحساب المستخدم (RLS)، ويُحذف مع حذف الحساب أو بـ«إعادة ضبط التوصيات».
إيقاف «تخصيص الريلز» يوقف تسجيل أى إشارة ويرجّع الترتيب العام. لا يتعلّم من إعلانات المستخدم نفسه. لا ينتقل ملف مستخدم لآخر على نفس الجهاز.
